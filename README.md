# Braille Trainer Prototype

A React Native mobile app paired with an ESP32-based braille display device for learning and practicing braille.

## Project Structure

- `mobile/` — React Native (Expo) mobile application
- `firmware/` — ESP32 firmware (PlatformIO)

## Tech Stack

**Mobile:** React Native, Expo SDK 54, NativeWind (Tailwind), TypeScript
**Backend:** Supabase (PostgreSQL, Auth)
**Firmware:** ESP32, PlatformIO, Arduino framework, C++
**Communication:** WiFi + WebSocket (JSON)
